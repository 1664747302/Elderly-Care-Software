# 老人关怀 (原：护眼休息提醒)

这是一个 Kotlin 原生 Android APK 项目，用于本地提醒老人减少长时间连续看手机、深夜防沉迷，并支持每日血压与心率测量自测打卡记录。

## 核心功能

### 1. 本地护眼休息提醒与防沉迷
- **使用权限引导**：引导开启 Android“使用情况访问权限”以了解前台应用运行情况。
- **定时后台检测**：每 15 分钟通过 WorkManager 周期性自动检查，手机重启后通过广播自动恢复。
- **连续使用提醒**：当检测到连续使用前台应用超时（默认 30 分钟）时，发送高优先级系统大字通知。
- **语音双轨播报**：支持 TextToSpeech 语音朗读，并提供“常规疲劳”与“深夜宵禁”两条轨道的家人自定义录音提醒。
- **深夜防沉迷 (夜间宵禁)**：当处于宵禁时段时，提醒阈值和冷却检测将自动收紧到 2 分钟，强力约束深夜作息。
- **本地视力与习惯周报**：收集 7 天本地提醒历史，由 Canvas 自定义绘制柱状图，直观展现用眼规律。

### 2. 血压与心率自测
- **自定义日期挑选**：自动载入今日日期，支持左右轻点“前一天/后一天”快捷切换，或点击日期通过日历控件精细回溯。
- **每日三测记录**：提供“早晨、中午、晚上”三个核心时段的测量卡片。
- **高/低压与心率填报**：采用防误触的输入校验，对三个数值生理极限与“收缩压必须大于舒张压”做强逻辑检验。
- **医学分类色卡和建议**：已填写的记录自动标识状态（血压正常、正常偏高、血压偏高、血压偏低），并提供针对性的生活作息调理与休息建议。
- **30天红线血压 Canvas score 折线/柱状图**：动态基于 Canvas 绘制最近 7 天的综合血压心率健康得分走势，清晰明确。
- **30天趋势大模型智能评估**：可通过家人设置页中灵活配置的 DeepSeek API Key 与自定义网关路由，一键开启基于大模型的智能血压健康助手。集成了客户端高压缩轻量传输（1KB以内）、24小时内科学防刷冷却期校验、7天记录前置风控拦截、极速原生异步多线程连接、安全离线瞬间回填持久缓存以及接口不可用时的健全错误排查降级显示指引。
- **自测历史回溯**：卡片式排列显示最近 15 次测量的历史列表，方便老人或子女查看。

### 3. 家人保护与隐私保护
- **PIN 安全认证**：涉及设置、周报和血压修改均由家人 PIN 密码保护，默认 PIN 为 `1234`。
- **纯本机零上传**：全部数据存储在本地 SQLite 数据库或 SharedPreferences 中，绝不上传至任何服务器，妥善防护老人隐私。

## 构建

推荐使用 Android Studio 打开本目录，等待 Gradle 同步完成后运行：

```powershell
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleDebug
```

如果首次运行下载 Gradle 或 Android Gradle Plugin 较慢，请保持网络连接后重试。

当项目位于中文路径或空格路径时，Android Gradle Plugin 在 Windows 上可以通过 `android.overridePathCheck=true` 构建 APK，但 `testDebugUnitTest` 的 JUnit worker 可能加载不到测试类。遇到这种情况，把项目复制到纯英文路径后运行单元测试，例如：

```powershell
robocopy "D:\Project\Elderly Care Software" "D:\elder_reminder_ascii" /E /XD .git .gradle .idea app\build /XF local.properties
Set-Content D:\elder_reminder_ascii\local.properties 'sdk.dir=D\:\\Android\\Sdk'
cd D:\elder_reminder_ascii
.\gradlew.bat testDebugUnitTest
```

## 真机使用

1. 安装生成的 `app-debug.apk` 到老人的智能手机上。
2. 首次打开应用，点击“开启使用情况权限”，并在系统页面中允许“老人关怀”。
3. 回到主界面进入“护眼项目”，点击“开始提醒”。
4. 点击“家人设置”，输入默认密码 `1234`，可修改提醒间隔、语音开关、录音和宵禁设置。
5. 每日可引导老人在主界面点进“血压自测”进行早中晚的数据记录。

## 注意

- Android 不允许普通应用自动开启“使用情况访问权限”，只能跳转系统页面由用户手动授权。
- WorkManager 的周期任务最小间隔为 15 分钟，因此提醒时间会接近阈值，不保证秒级精确。
- 手机可能会限制后台任务。请根据设置页中的保活配置教程，在系统电池/应用启动管理里允许本应用自启动与后台运行。
- 本应用只做生活习惯与自测提醒，填报数值用于对比记录，不提供医学诊断或临床治疗建议。

## 历史更新日志

### v2.0 - 2026-05-27 (最新版本)
- **无障碍服务极其精准守护**：彻底重构了使用时间监测逻辑，新增基于 Android 无障碍系统服务（`ElderAccessibilityService`）的前台实时检测。能高灵敏度的在秒级内获取用户前台应用状态，低能耗完美解决 WorkManager 最小 15 分钟周期调度的体验延误。
- **休息判定阻尼防作弊算法**：支持自定义“休息判定时间阻尼缓冲”时长（通过 `restGracePeriodMinutes` 字段，范围 1~30 分钟），能智能拦截老人用“秒回桌面”或“瞬间灭屏”卡系统漏洞无限续杯手机的作弊行为，必须真正离线休息满缓冲时长后方重置累计时间。
- **强制最大音量与高对比度 Activity 弹窗**：新增 `ReminderDialogActivity` 强拉起全屏层阻断。不论在此之前是否有前台第三方应用在运行，一旦触及阈值便立即拉起专为老人设计的巨字高色度护眼提示界面，自动调用系统 `AudioManager` 强制拉满媒体音量通道播放录音或 TTS，保障高疲劳场景下的绝对唤醒感。
- **二级页面顶部导航与首页返回统合**：为应用内所有子功能页面统合追加了“返回 + 中间正规标题 + 首页一键直达 (Clear Top 模式)”的顶部轻量导航卡片，大幅改善无虚拟键场景下的回退友好性。
- **血压智能评估**：新增基于 DeepSeek 大模型的 30 天血压心率趋势分析评估功能。支持家人在控制面板输入自定义的 API Key 与接口路由网关。
- **客户端数据高密压缩与智能防护**：手写零依赖的轻量流编码将 30 天低频高点（早/中/晚）血压测量压缩在 1KB 以内。配置 24 小时分析冷却防刷限流器与 7 天血压数据初筛机制，保证高效稳定。
- **健康评分Canvas大屏可视化**：重新重构了血压自测大卡，新增 Canvas 绘制血压评分柱形图，生动呈现 7 天历史趋势。

### v1.1 - 2025-05-25
